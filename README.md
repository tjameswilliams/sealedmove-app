# Sealed Move — app source

This is the corresponding source for the [Sealed Move](https://sealedmove.com)
iOS app: the SwiftUI client and the Rust coaching engine it statically
links. It exists because the app embeds
[Stockfish 11](https://stockfishchess.org), which is licensed under the
GNU General Public License v3 — so the combined work that ships on the App
Store is a GPL work, and here is its source.

Each App Store release is tagged with its version number (`v0.1.0`, …),
so the source for the exact build on your phone is a tag away.

## Layout

| Path | What it is |
|---|---|
| `apps/ios` | The SwiftUI app (project generated by xcodegen) |
| `crates/coach-core` | Coaching engine: engine analysis, judgment, commentary policy, student model, store |
| `crates/coach-ffi` | UniFFI bindings exposing coach-core to Swift |
| `crates/coach-cli` | Terminal harness for the same engine |
| `crates/stockfish-embedded` | Stockfish 11 compiled in-process (the GPL boundary — see its README) |

## Build

Requires: Rust (with `aarch64-apple-ios` and `aarch64-apple-ios-sim`
targets), Xcode, [xcodegen](https://github.com/yonaskolb/XcodeGen).

```sh
# 1. Build the Rust core into an XCFramework
./scripts/build-ios-xcframework.sh

# 2. Generate the Xcode project and build
cd apps/ios
xcodegen
xcodebuild -project TeachMeChess.xcodeproj -scheme TeachMeChess \
  -destination 'generic/platform=iOS Simulator' build
```
