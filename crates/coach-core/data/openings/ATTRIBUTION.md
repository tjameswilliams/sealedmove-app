# Opening database attribution

The TSV files in this directory (`a.tsv` … `e.tsv`) are vendored unmodified
from the lichess.org chess openings database:

- Source: https://github.com/lichess-org/chess-openings
- License: CC0 1.0 Universal (public domain dedication)

Columns: `eco`, `name`, `pgn` (tab-separated, one header row per file).
